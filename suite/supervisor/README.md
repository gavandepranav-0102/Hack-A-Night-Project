# BuildProof AI - Supervisor Dashboard (React + Vite + Tailwind)

    npm install
    npm run dev      # open http://localhost:5173  (phones: use the Network URL over HTTPS, e.g. via a tunnel)

Both buttons open a live camera preview (getUserMedia, rear camera preferred). There is no file picker or gallery option.
Camera access needs HTTPS or localhost. Submission is a DEMO handler in `src/services/submitEvidence.js` - replace it with your API call.
